# Datenschutzerklärung

Diese Website dient ausschließlich als Konfigurations- und Informationsseite für die Erstellung einer persönlichen Google OAuth Client ID zur Verwendung mit dem Backup-Tool **rclone**.

## Datenverarbeitung
- **Keine Datenerhebung:** Diese Website selbst (gehostet über GitHub Pages) sammelt, speichert oder verarbeitet keinerlei personenbezogene Daten der Besucher.
- **rclone & Google Drive:** Wenn Sie rclone mit einer eigenen Client ID autorisieren, findet die gesamte Datenkommunikation ausschließlich direkt zwischen Ihrem lokalen Computer und den offiziellen Google-APIs statt. Es werden zu keinem Zeitpunkt Daten an den Ersteller dieser Seite oder an Dritte übertragen.
- **Berechtigungen:** rclone greift nur auf die von Ihnen explizit freigegebenen Google Drive-Dateien zu, um die von Ihnen eingerichteten Sicherungen (Backups/Syncs) durchzuführen.

## Kontakt
Bei Fragen zum Datenschutz können Sie sich an den Betreiber dieses GitHub-Repositories wenden.
